# Polices embarquées

Noto Sans, Noto Serif et Noto Sans Mono (projet Noto, version « unhinted »
du dépôt `notofonts/notofonts.github.io`, téléchargées le 17/11/2026),
sous licence SIL Open Font License 1.1 (`OFL.txt`), livrée avec
l'application.

Elles servent au texte ajouté qui sort de l'alphabet latin d'Europe de
l'Ouest (grec, cyrillique, latin étendu) : les polices standard du PDF ne
le couvrent pas. Empreintes : `SHA256SUMS` (vérifiées par les tests).
Noto Sans Mono n'a pas d'italique : la chasse fixe reste droite.
